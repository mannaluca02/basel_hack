# Pax LifeMap

Begriffe für die Aufnahme persönlicher Angaben aus dem Beratungsgespräch.

## Sprache

**Unterhaltungslog**:
Der Dialog zwischen beratender KI und antwortender Person mit unterscheidbaren Sprecherrollen. KI-Aussagen sind Gesprächskontext, keine eigenständigen Angaben der Person.

**Feldvorschlag**:
Eine aus dem Gespräch erkannte Angabe zur Übernahme in ein festgelegtes Fallfeld, die noch auf Bestätigung durch die Person wartet.
_Vermeiden_: bestätigte Angabe für einen lediglich erkannten Wert.

**Bestätigte Angabe**:
Eine Angabe, deren Übernahme die Person ausdrücklich bestätigt hat. Eindeutige Erkennung allein ist keine Bestätigung.

**Unklarheit**:
Eine offene Mehrdeutigkeit, fehlende Präzisierung oder ein Widerspruch bei der Aufnahme einer Angabe, verbunden mit einer klärenden Frage. Eine spätere Antwort kann die Unklarheit auflösen.

**Beantwortete Unklarheit**:
Eine fachlich noch offene Unklarheit, für die eine passende Antwort bereits zur Annahme vorliegt. Sie benötigt eine Entscheidung über die Übernahme statt einer erneuten Rückfrage.

**Bestätigungsanforderung**:
Eine konkrete, der Person gestellte Bitte um Zustimmung zu genau einer benannten Aktion auf einem bestimmten Fallstand. Die Annahme einer Änderung und die Bestätigung des Gesamtprofils sind unterschiedliche Aktionen.
