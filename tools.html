How to use it

Every operation is a POST to the path /operation/standard/<operationId> with a JSON body. Example with curl:

curl -X POST "https://baselhackathon2026.azurewebsites.net/viper/operation/standard/APICalc_getSaving3aLimits" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{}'

Find locations (TaxLocationID) via APICalc_searchLocation (search by postcode or town). If a required API key is missing, the server responds with 401.
