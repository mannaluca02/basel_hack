# Wallpaper logo sources

Local assets used on the presentation's simulated iPhone lock screens:

- Pax: existing official logo bundle in `assets/pax/logos/online/colour-negative/`.
- BaselHack: [official website logo](https://www.baselhack.ch/img/baselhack_white_resized.webp), downloaded 2026-11-01 from [baselhack.ch](https://www.baselhack.ch/).
- OpenAI: the user-requested [2017 wordmark](https://commons.wikimedia.org/wiki/File:OpenAI_wordmark_2017.svg), [original SVG](https://upload.wikimedia.org/wikipedia/commons/a/a0/OpenAI_wordmark_2017.svg), downloaded 2026-11-01. The file is unchanged; CSS inverts the black mark for the dark wallpaper.

The original logo files are unchanged. Screen dimming and wallpaper gradients are presentation effects. The logos identify the challenge organisation and technology used; they do not imply endorsement of the project. The iPhone-style frame is an original presentation SVG with a 390 × 844 screen viewport matching the supplied screenshot's proportions.
