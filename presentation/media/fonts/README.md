# Pax Civil fonts

Typography follows the [Pax brand typography capture](../../../documentation/baselhack/references/web/design/brand/pax-brand-typography.txt) and the [Pax UI typography capture](../../../documentation/baselhack/references/web/design/components/pax-ui-typography.txt) in this repository.

- Pax Civil Bold (700): headings, titles and emphasis.
- Pax Civil Regular (400): body copy.
- Pax Civil Medium (500): buttons and interface labels.
- Arial: the documented system fallback.

The presentation keeps its existing wording, capitalization, sizes, colours, layout and animation sequence. Browser screenshot text and system status text retain iPhone/Chrome typography.

The three files were downloaded from the public Pax website assets recorded in `documentation/baselhack/catalog/public-pension-analysis.json`:

- [Regular](https://www.pax.ch/_astro/PaxCivil-Regular.CWZl4kFD.woff2)
- [Medium](https://www.pax.ch/_astro/PaxCivil-Medium.BtzKDZjB.woff2)
- [Bold](https://www.pax.ch/_astro/PaxCivil-Bold.WncZdeDT.woff2)

Pax Civil is Pax's brand font; these files are included for this Pax challenge presentation, not presented as generally licensed fonts.
